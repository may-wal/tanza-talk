# Tanza Talks — Website (Front End)

A React + Tailwind CSS recreation of the Tanza Talks landing page —
fully mobile responsive, front-end only (no backend).

## Start here

- 👉 **First time setting this up?** Read **`SETUP.md`** — step-by-step
  instructions to install and run the project, even if you've never used
  React before.
- 👉 **Want to know where a section lives or how it works?** Read
  **`INFORMATION.md`** — a full map of every section on the page, which
  file renders it, which file holds its text, and how its logic works.

## Quick start (if you already have Node.js)

```bash
npm install
npm run dev
```

Then open the local URL it prints (usually `http://localhost:5173`).

## Tech stack

- React 19 + Vite
- Tailwind CSS
- lucide-react + react-icons (icons)
- Images from Unsplash (hotlinked, no local image files)
